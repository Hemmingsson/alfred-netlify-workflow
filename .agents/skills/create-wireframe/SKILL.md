# Create a documentation wireframe

Use this project copy in preference to the global skill of the same name.
For behaviour, dependencies or message order, use
[create-diagram](../create-diagram/SKILL.md).

1. Read [the shared visual style](../../visual-style.md). Inspect the closest
   current export and its generator before drawing. The canonical layout is
   [site-browser-elements.svg](../../../assets/diagrams/site-browser-elements.svg);
   state comparisons are `site-browser-variants.svg` and `account-states.svg`
   in that same folder.
2. Check the shipped UI in `workflow/sites.alfredui/` and the relevant
   `Sources/NetlifyWindow/` presenter. Record which real layout and state the
   drawing explains. Draw the visible structure, not an imagined redesign.
3. Extend `demo/diagrams/build-wireframes.py`, reusing `Sheet`, `icon`,
   `browser_bar` and `picture`. Hand-authored SVG generated by this script is
   the established wireframe route. Keep reusable geometry and theme CSS in
   the generator, not patched only in its exports.
4. Build one default layout sheet, then only the comparisons needed:
   - Default: one labelled result row, skeletons for the rest, selected-row
     fill, search, cache status and a single preview region. Keep Refresh the
     same text size as the status. Use a few leaders for relationships that
     the controls themselves do not explain.
   - Preview comparison: Live page / Picture fallback / No preview.
   - Account comparison: Signed out / Connecting / First refresh failed.
     These replace the whole window content; they are not a detail-pane state.
   Keep the two three-window comparisons separate. Add a full login sheet only
   when a document needs it; do not generate an unreferenced duplicate.
5. Match real controls: vector paths for back, forward, reload and globe;
   square navigation and viewport corners; rounded action buttons with the
   actual labels, shortcut glyphs and right alignment. Copy UI symbols as
   vector geometry, not emoji or substitute text arrows. Outer windows may
   retain their real corner radius. Structural placeholders need only one
   short content label, without sizing annotations.
6. Run from the repository root:

   ```sh
   python3 demo/diagrams/build-wireframes.py
   python3 demo/diagrams/style-diagrams.py
   ```

   The second command needs `resvg` and refreshes PNGs. Inspect the generated
   SVG/HTML as well as the PNG: a PNG alone cannot prove theme support.
7. Apply the shared delivery and verification checks. Regeneration may touch
   unrelated exports; inspect the diff and retain only intended changes. The
   result is complete when the relevant document embeds the SVG and the
   source reproduces it without reintroducing titles or redundant annotations.
